## 번역 원칙

- 화면에서 찾아야 하는 UI 레이블, 버튼, 탭, 필드명은 **영어 원문 그대로** 둡니다.
- 학습자가 입력해야 하는 값(스키마 이름, URL, 변수명, 프롬프트, 수식)은 **번역하지 않습니다**. 글자 하나만 달라도 실습이 실패합니다.
- 각 단원과 랩 머리에 해당 **원문 링크**를 답니다.
- 원문에 없는 사실이나 수치를 지어내지 않습니다. 이해를 돕는 설명은 덧붙이되 제품 사실은 원문 범위 안에서만 씁니다.

## 저작권

원문 내용과 화면 이미지의 저작권은 Microsoft에 있습니다. Microsoft의 공식 한국어 현지화가 아닙니다. 자세한 내용은 [NOTICE.md](NOTICE.md)를 참고하세요.

## 원본 변경 추적

원문이 갱신되면 반영합니다. 감시 스크립트는 Learn 페이지의 커밋 해시와 랩 저장소의 파일별 최신 커밋 SHA를 지문으로 삼아 실제 변경만 잡아냅니다.
