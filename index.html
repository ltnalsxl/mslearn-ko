Microsoft Copilot Studio

Microsoft Learn의 Copilot Studio 학습 모듈과 실습 랩을 한국어로 옮기고 설명을 덧붙였습니다. 원문에 실린 화면 이미지를 모두 포함했습니다.

문서 2종화면 이미지 117장2026년 9월 기준
읽기 전에

이 사이트는 학습 편의를 위해 만든 비공식 번역본입니다. Microsoft의 공식 한국어 현지화가 아니며, Microsoft를 대표하지 않습니다.

Copilot Studio는 기능과 화면이 빠르게 바뀝니다. 이 사이트는 2026년 9월 기준이므로, 정확한 내용 확인을 위해서는 각 문서 단원 머리의 원문 링크를 눌러 최신 내용을 확인해 주세요.

원문 내용과 화면 이미지의 저작권은 Microsoft에 있습니다. 자세한 내용은 저작권 고지를 참고하세요.

12개 단원이미지 36장읽기 약 50분

Copilot Studio 실습

Copilot Studio exercises

환경 준비부터 에이전트 생성, 토픽 관리, 지식 연결, 워크플로 도구, 새 제작 환경까지 여섯 개 랩을 단계별로 따라갑니다.

랩 6개이미지 81장실습 약 4시간

권장 학습 순서

  1. 시작하기 1~5단원을 읽어 에이전트, 환경, 하네스 개념을 잡습니다.
  2. 실습 랩 00으로 환경과 솔루션을 준비합니다.
  3. 실습 랩 01로 에이전트를 하나 만들어 봅니다.
  4. 시작하기 6~7단원으로 토픽과 생성형 AI를 이해합니다.
  5. 실습 랩 02~04로 토픽, 지식, 도구를 차례로 다룹니다.
  6. 시작하기 8~9단원으로 테스트와 게시를 정리합니다.
  7. 실습 랩 05로 새 제작 환경을 경험하고 두 방식을 비교합니다.
시작 전에

회사 또는 학교 계정과 Copilot Studio 라이선스(또는 무료 체험판)가 필요합니다. 개인 Microsoft 계정으로는 진행할 수 없습니다.
