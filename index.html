Microsoft Learn 한국어판

Microsoft Learn의 Copilot Studio와 Microsoft 365 Copilot 학습 모듈·실습 랩을 한국어로 옮기고 설명을 덧붙였습니다. 원문에 실린 화면 이미지를 모두 포함했습니다.

코스 11종화면 이미지 280여 장2026년 9월 기준
읽기 전에

이 사이트는 학습 편의를 위해 만든 비공식 번역본입니다. Microsoft의 공식 한국어 현지화가 아니며, Microsoft를 대표하지 않습니다.

Microsoft Learn의 코스 본문은 한국어가 제공되지만, GitHub에 올라 있는 실습 랩 지시문은 영어로만 제공됩니다. 이 사이트는 그 실습 랩을 한국어로 옮긴 것입니다.

Copilot은 기능과 화면이 빠르게 바뀝니다. 이 사이트는 2026년 9월 기준이므로, 정확한 내용 확인을 위해서는 각 문서 단원 머리의 원문 링크를 눌러 최신 내용을 확인해 주세요.

원문 내용과 화면 이미지의 저작권은 Microsoft에 있습니다. 자세한 내용은 저작권 고지를 참고하세요.

랩 1개관리자

Copilot 도입을 위한 보안과 규정 준수 준비

MS-4002 · Prepare security and compliance to support Microsoft 365 Copilot

테넌트 초기화, 사용자 접근 관리, 역할과 역할 그룹, DLP 정책, 민감도 레이블을 차례로 다룹니다. Copilot을 켜기 전에 해야 할 준비 작업입니다.

준비 중랩 4개관리자·보안

Purview로 Copilot 상호작용 보호하고 통제하기

SC-5010 · Secure and govern Microsoft 365 Copilot interactions with Microsoft Purview

Microsoft Purview로 Copilot 사용 기록을 감사하고 통제하는 방법을 다룹니다.

랩 1개보안·컴플라이언스

어디부터 볼까

  1. Copilot을 처음 쓴다면 Copilot Chat 살펴보기와 웹용 Copilot 실습부터 봅니다.
  2. 업무에 본격적으로 붙이려면 작성·분석·발표를 하고, 자기 직군에 맞는 직군별 활용 모듈을 이어서 합니다.
  3. 에이전트를 직접 만들려면 Copilot Studio 시작하기에서 개념을 잡고 Copilot Studio 실습으로 넘어갑니다.
  4. Copilot 안에서 동작하는 에이전트를 만들려면 MS-4022 확장을 봅니다.
  5. 도입을 준비하는 관리자라면 Purview로 보호하고 통제하기부터 봅니다. 보안과 규정 준수 과정은 준비 중입니다.
시작 전에

대부분의 실습에 회사 또는 학교 계정이 필요합니다. Copilot Studio 실습에는 라이선스나 무료 체험판이, Microsoft 365 Copilot 실습에는 Copilot 라이선스가 있는 테넌트가 필요합니다. 개인 Microsoft 계정으로는 진행할 수 없습니다.
