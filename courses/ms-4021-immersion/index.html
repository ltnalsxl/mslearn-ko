Copilot 몰입 체험

임원과 각 부서 담당자가 Microsoft 365 Copilot을 직접 만져 보는 체험 세션 자료입니다. Microsoft Learn의 Copilot Immersion Experience(MS-4021)를 한국어로 옮기고, 원문에 실린 화면 이미지를 포함했습니다.

부서 데모 13종 임원 실습 9종 프롬프트 16종 원문 38개 문서
원문을 함께 확인해 주세요

이 문서는 Microsoft Learn 실습 자료 MS-4021 Copilot Immersion Experience를 한국어로 옮긴 비공식 번역본입니다. 원문은 영어로만 제공됩니다.

Copilot은 기능과 화면이 빠르게 바뀝니다. 이 문서는 2026년 9월 기준이므로, 정확한 내용은 각 페이지 단원 머리의 원문 링크를 눌러 최신 버전으로 확인해 주세요.

Copilot에 입력하는 프롬프트와 값은 원문 그대로 두었습니다. 번역하면 결과가 달라지므로 영어 표기 그대로 사용하시면 됩니다.

화면 이미지와 원문 내용의 저작권은 Microsoft에 있습니다.

이 체험은 무엇인가

Copilot 몰입 체험은 리더와 실무자가 회의실에 모여 Microsoft 365 Copilot을 손으로 직접 다뤄 보는 세션입니다. 슬라이드로 설명만 듣는 자리가 아니라, 각자 자기 업무에 가까운 시나리오를 골라 프롬프트를 입력하고 결과를 눈으로 확인합니다. 세션은 크게 세 갈래로 구성됩니다.

세 갈래

진행자가 앞에서 보여 주는 부서별 데모, 임원이 직접 손을 대는 임원 실습, 참석자가 자기 역할에 맞춰 골라 쓰는 역할별 프롬프트 모음으로 나뉩니다. 세 갈래는 서로 이어지도록 설계되어 있습니다.

누가 어떤 순서로 쓰나

세션 진행자와 참석자가 역할에 따라 다른 갈래를 씁니다. 아래 순서를 기본으로 삼되 현장 구성에 맞춰 조정하시면 됩니다.

  1. 진행자는 세션을 열며 부서별 데모에서 청중에 맞는 시나리오를 두세 개 골라 시연합니다. 임원 대상이라면 임원, 커뮤니케이션, 재무 데모가 무난합니다.
  2. 임원 참석자는 시연을 본 뒤 임원 실습으로 넘어가 Copilot을 직접 사용해 봅니다. Business Chat, Word, Outlook처럼 익숙한 지점부터 시작합니다.
  3. 부서 담당자는 프롬프트 모음에서 자기 역할을 찾아, 준비된 프롬프트를 자기 업무 맥락으로 바꿔 가며 실습합니다.
  4. 세션 후반에는 임원이 AI 아스피레이션과 90일 계획 프롬프트로 구체적인 실행 계획을 세웁니다.
팁

데모와 실습에 쓰는 예제 파일은 원문 저장소의 ResourceFiles 폴더에 있습니다. 세션 전에 파일을 내려받아 OneDrive에 올려 두면 동기화 지연으로 흐름이 끊기는 일을 막을 수 있습니다.

준비 중

세 갈래의 한국어 페이지는 아직 만드는 중입니다. 지금은 아래 요약으로 구성을 확인하시고, 실제 내용은 원문 저장소에서 보시면 됩니다.

부서별 데모 13종

진행자가 앞에서 보여 주는 시연 자료입니다. 임원, 커뮤니케이션, HR, 영업, IT, 임원 비서, 사업 관리자, 마케팅, 운영, 법무, 재무, 리서처·분석가, Copilot Studio를 다룹니다.

임원 실습 9종

임원이 직접 Copilot을 다뤄 보는 실습입니다. Business Chat과 Pages, Word, Outlook, Teams, Excel 등 사용 지점별로 나뉩니다.

프롬프트 모음 16종

역할과 주제별 프롬프트 모음입니다. 부서별 몰입 실습과 임원용 AI 계획 워크숍, 에이전트 만들기 실습이 들어 있습니다.

원문과 라이선스

원문 저장소는 MicrosoftLearning/MS-4021-Copilot-Immersion-Experience(브랜치 master)입니다. 게시본은 GitHub Pages에서 볼 수 있습니다.

이 자료는 실제 임원 세션 진행에 쓰이는 강사용 자료입니다. 진행자가 청중과 환경에 맞춰 내용을 골라 쓰도록 설계되어 있으므로, 모든 시나리오를 한 세션에서 다 다루지 않아도 됩니다.
