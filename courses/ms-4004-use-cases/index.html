직군별 Microsoft 365 Copilot 활용

Microsoft Learn MS-4004 코스의 직군별 실습 10개 모듈을 한국어로 옮겼습니다. 임원부터 법무까지 각자 하는 일에 Copilot을 어떻게 붙이는지 프롬프트 단위로 따라갑니다.

모듈 10개 모듈당 약 44분 수준 200 2026년 9월 기준
원문을 함께 확인해 주세요

이 문서는 Microsoft Learn 실습 랩 MS-4004 Empower your workforce with Microsoft 365 Copilot use cases를 한국어로 옮긴 자료입니다. 원문 랩은 영어로만 제공됩니다.

Copilot은 기능과 화면이 빠르게 바뀝니다. 이 문서는 2026년 9월 기준이므로, 정확한 내용 확인을 위해서는 각 모듈 안의 원문 링크를 눌러 최신 내용을 확인해 주세요.

Copilot에 입력할 프롬프트는 원문 그대로 두었습니다. 영어 표기 그대로 사용하시면 됩니다.

화면 이미지와 원문 내용의 저작권은 Microsoft에 있습니다.

누구를 위한 자료인가

Copilot 기능을 개념으로 설명하는 자료가 아닙니다. 직군마다 실제로 처리하는 업무를 시나리오로 잡고, 그 자리에서 어떤 프롬프트를 어떤 앱에 넣는지 하나씩 따라 하는 실습입니다.

이 코스가 다루는 것
  • Word, Excel, PowerPoint, Outlook, Teams, Planner에서 Copilot으로 실제 산출물을 만드는 절차
  • 업무에 맞춘 에이전트를 만들고 쓰는 방법
  • 직군마다 다른 자료와 맥락을 프롬프트에 어떻게 실어 보낼지

공통 사전 준비

모듈 10개가 같은 준비 과정을 공유합니다. 어느 모듈을 먼저 하든 이 준비를 한 번만 해 두면 됩니다.

중요

Microsoft 365 Copilot은 OneDrive에 저장된 파일만 다룰 수 있습니다. PC에 로컬로 저장된 파일은 Copilot이 읽지 못하므로 OneDrive로 옮겨야 합니다.

실습 파일을 OneDrive에 올리기

  1. 테넌트 제공자가 준 가상 머신에 로컬 Administrator 계정으로 로그인합니다.
  2. 작업 표시줄에서 Microsoft Edge를 선택합니다.
  3. 주소 표시줄에 https://www.office.com을 입력합니다.
  4. Welcome to Microsoft 365 아래에서 Sign in을 선택합니다.
  5. 로그인 창에 테넌트 제공자가 준 계정(userx@yourtenant.onmicrosoft.com 형식)을 입력하고 Next를 선택합니다.
  6. 암호를 입력하고 Sign in을 선택합니다.
  7. Stay signed in 창이 뜨면 Don't show this again을 체크하고 Yes를 선택합니다.
  8. Apps에서 OneDrive를 엽니다.
  9. 왼쪽 위 +에서 File upload를 선택합니다.
  10. 파일 탐색기에서 This PC > Local Disk (C:)의 ResourceFiles 폴더를 엽니다.
  11. 폴더 안 파일을 모두 선택하고 Open을 선택해 업로드합니다.
  12. 화면 아래에 Uploaded 29 items to My files가 뜨면 업로드가 끝난 것입니다. Edge는 그대로 열어 둡니다.

Copilot이 파일을 찾지 못할 때

프롬프트에서 파일을 참조하려는데 후보 목록에 안 뜨는 경우가 있습니다. Copilot 경험에 따라 최근 사용 목록(MRU)만 참조하는 곳과 OneDrive를 직접 탐색할 수 있는 곳이 나뉘기 때문입니다. 해당 파일을 그 앱에서 한 번 열면 최근 사용 목록에 올라가 곧바로 참조할 수 있습니다.

프롬프트 네 가지 요소

모든 모듈이 같은 프롬프트 작성 틀을 씁니다. 실습을 시작하기 전에 이 네 가지를 익혀 두면 남은 내용이 훨씬 빨리 붙습니다.

Goal · 목표

Copilot이 무엇을 해야 하는지 분명히 적습니다. "최근 프로젝트 업데이트를 요약해 불릿 3~5개로 만들어 줘"처럼 씁니다.

Context · 맥락

왜 필요한지, 누구와 무엇이 얽혀 있는지 배경을 줍니다. "Client X와의 Phase 3+ 브랜드 캠페인 회의용이야"처럼 씁니다.

Sources · 출처

어디를 보고 답하라고 지정합니다. 문서, 메일, Teams 대화 등입니다. "6월 이후 메일과 Teams 대화만 봐"처럼 씁니다.

Expectations · 기대

어떤 형태로 받고 싶은지 정합니다. 어조, 문체, 상세 수준입니다. "빨리 파악할 수 있게 쉬운 말로 써 줘"처럼 씁니다.

권장 진행 방식

  1. 위의 공통 사전 준비를 한 번 마칩니다. 실습 파일이 OneDrive에 올라가 있어야 나머지가 진행됩니다.
  2. 프롬프트 네 가지 요소를 읽습니다. 모듈마다 반복되는 틀이라 여기서 한 번 잡아 두면 됩니다.
  3. 자기 직군 모듈을 처음부터 끝까지 따라 합니다. 모듈 하나가 대략 44분입니다.
  4. 여유가 있으면 인접 직군 모듈을 하나 더 봅니다. 임원과 재무, 영업과 마케팅, 운영과 고객 서비스가 서로 이어집니다.
교육에 쓸 때

모듈이 독립적이라 참가자를 직군별로 나눠 동시에 진행하기 좋습니다. 공통 사전 준비만 시작 전에 함께 마치면 됩니다.
