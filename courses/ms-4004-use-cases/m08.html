원문Lab Setup & Introduction

커뮤니케이션 업무와 Copilot

커뮤니케이션 담당자는 명확하고 설득력 있는 메시지를 제때, 알맞은 채널로, 알맞은 대상에게 전달해야 합니다. Microsoft 365 Copilot은 전략적 프롬프트로 콘텐츠 제작을 간소화하고 메시지 일관성을 높이며 워크플로를 효율화하도록 돕습니다. Word에서 보도자료를 다듬든, SharePoint에서 캠페인 자산을 모으든, Outlook으로 사내 뉴스레터를 만들든, PowerPoint로 리더십 브리핑을 준비하든 Copilot이 도구 상자의 한 축이 됩니다.

커뮤니케이션 분야에서 Copilot을 잘 쓰는 능력은 다음에 특히 중요합니다.

  • 콘텐츠 제작 간소화. 보도자료, 사내 메모, 리더십 메시지의 초안을 잡고 톤을 다듬으며 브랜드 보이스에 맞춥니다.
  • 편집 워크플로 강화. 긴 초안을 요약하고 불일치를 찾아 명확성과 톤을 개선합니다.
  • 이해관계자 정렬 개선. 회의나 이메일 스레드에서 요약을 만들어 메시지가 리더십 우선순위와 어긋나지 않게 합니다.
  • 커뮤니케이션 계획 최적화. 일정을 세우고 메시지 승인을 추적하며 게시 일정을 채널별로 조율합니다.

실습 파일을 OneDrive에 올리기

이 모듈의 Copilot 프롬프트는 파일을 참조합니다. 먼저 실습에 필요한 파일을 모두 OneDrive에 올려 실습 내내 접근할 수 있게 합니다.

  1. 테넌트 제공자가 준비한 가상 머신에 로컬 Administrator 계정으로 로그인합니다. 암호는 Pa55w.rd입니다.
  2. Windows 작업 표시줄에서 Microsoft Edge를 선택합니다.
  3. 주소 표시줄에 https://www.office.com을 입력합니다.
  4. Welcome to Microsoft 365 화면에서 Sign in을 선택합니다.
  5. Sign-in 창에서 테넌트 제공자가 준 사용자 이름 userx@yourtenant.onmicrosoft.com을 입력하고 Next를 선택합니다.
  6. Enter password 화면에서 사용자 계정 암호를 입력하고 Sign in을 선택합니다.
  7. Stay signed in이 나오면 Don't show this again을 선택한 뒤 Yes를 선택합니다.
  8. Microsoft 365에서 Apps를 선택하고, 이어서 OneDrive를 선택합니다.
  9. OneDrive 왼쪽 위에서 +(add new) > File upload을 선택합니다.
  10. File Explorer에서 This PC > Local Disk (C:)로 이동해 ResourceFiles 폴더를 엽니다.
  11. 폴더 안 파일을 모두 선택하고 Open을 선택해 OneDrive로 올립니다.
  12. 업로드가 끝나면 화면 아래 가운데에 Uploaded 29 items to My files가 보입니다. Edge는 열어 둔 채 다음 단계로 넘어갑니다.
참고 · MRU 목록

Copilot에서 일부 파일이 제안 목록에 바로 뜨지 않을 수 있습니다. 어떤 Copilot 환경은 Most Recently Used(MRU, 최근 사용) 목록의 파일만 참조하고, 어떤 환경은 OneDrive를 직접 탐색합니다. 파일을 MRU 목록에 올리려면 해당 Microsoft 365 앱에서 그 파일을 한 번 열면 됩니다.

중요

Microsoft 365 Copilot은 OneDrive에 저장한 파일만 다룰 수 있습니다. PC에만 저장된 파일은 Copilot이 접근하려면 OneDrive로 옮겨야 합니다.

효과적인 프롬프트의 네 가지 요소

Copilot을 잘 쓰는 핵심은 프롬프트의 품질입니다. 좋은 프롬프트는 요청을 명확하고 실행 가능하게 만드는 다음 네 가지를 담습니다.

Goal (목표)

Copilot이 무엇을 하기를 원하는지 분명히 밝힙니다. 예: “최근 프로젝트 업데이트를 요약한 불릿 3~5개를 만들어 줘.”

Context (맥락)

왜 이 요청이 필요하고 누가·무엇이 관련되는지 배경을 줍니다. 예: “Client X의 ‘Phase 3+’ 캠페인 회의에 쓸 불릿이야.”

Sources (원본)

어디에서 정보를 찾을지 지정합니다. 예: “6월 이후의 이메일과 Teams 채팅에 집중해 줘.”

Expectations (기대)

톤, 스타일, 상세 수준을 정합니다. 예: “빨리 파악하게 쉬운 표현으로 설명해 줘.”

첫 프롬프트만 제공됩니다

각 연습의 첫 프롬프트는 이 네 요소를 담은 예시로 원문 그대로 제공됩니다. 나머지 프롬프트는 직접 작성하되, 이 예시를 본보기로 삼으면 됩니다. 원하는 결과가 나오지 않으면 프롬프트를 조금씩 바꿔 다시 시도합니다.

AuroraHub는 메시지를 간소화하고 직원 사기를 높이며 참여를 실시간으로 측정하도록 설계된 사내 커뮤니케이션 플랫폼입니다. 커뮤니케이션 팀의 선임으로서 임원 리더십용 전략 브리프를 만듭니다. 브리프는 플랫폼을 소개하고, 핵심 기능과 이점을 정리하며, 회사 전략 목표와의 정렬과 사업 가치를 보여 줘야 합니다. 이 과제는 Edit with Copilot 기능을 씁니다.

과제 3 · Copilot in Excel로 커뮤니케이션 지표 분석

원문Exercise 1, Task 3: Use Copilot in Excel

분기 뉴스레터가 부서별로 어떻게 소비되는지, 특히 지난 분기의 개봉률과 클릭률을 리더십이 요약해 달라고 합니다. 개봉률(open rate)은 받은 사람 중 몇 명이 열었는지를, 클릭률(click-through rate)은 연 사람 중 몇 명이 안의 링크를 눌렀는지를 나타냅니다. Copilot in Excel로 부서별 참여를 분석해 트렌드를 빠르게 드러냅니다. 이 과제는 Edit with Copilot과 기본 Auto 선택기를 씁니다.

참고 · 선택기 차이

Copilot for Excel의 응답 선택기는 어떤 AI 모델로 작업할지 고르는 것이고, Copilot Chat의 선택기는 추론 깊이를 정하는 것입니다. 비슷해 보여도 서로 다른 설정입니다.

  1. Boulder Q4 Newsletter Click Rates.xlsx 파일을 내려받아 OneDrive에 저장합니다.
  2. Edge에서 Microsoft 365 홈으로 갑니다.
  3. Apps > Excel을 선택합니다.
  4. Excel for the web에서 Upload a file 버튼을 선택하고 OneDrive에서 Boulder Q4 Newsletter Click Rates 파일을 엽니다.
  5. Home 탭 리본에서 Copilot을 선택합니다. 응답 모드 선택기는 Auto로 두고, 프롬프트 필드에 Edit with Copilot 아이콘이 있는지 확인합니다. 없으면 더하기 > Edit with Copilot을 선택합니다.
  6. 미리 정의된 프롬프트 대신 직접 입력합니다. 열린 스프레드시트의 트렌드를 요약하고 평균 이하 참여 부서를 짚어 새 시트에 표시해 달라고 요청합니다.
  7. 결과를 검토하고 Sheet1로 돌아옵니다. 부서별 개봉률과 클릭률을 비교하는 막대 차트를 새 시트에 추가해 달라고 요청합니다.
  8. 차트를 검토하고 Sheet1로 돌아옵니다. 클릭률 기준으로 부서 순위를 매기고 상위 세 곳과 하위 세 곳을 강조해 새 시트에 표시해 달라고 요청합니다.
  9. 응답을 검토하고 Sheet1로 돌아옵니다. 리더십 보고용으로, 전체 평균 개봉률과 클릭률, 평균 이하 참여 부서를 담은 짧은 요약을 만들고 저성과 부서의 개봉·클릭률 개선 제안을 더해 새 시트에 표시해 달라고 요청합니다.
  10. 응답을 검토합니다. 더 보탤 것이 있는지 Copilot에 묻고, 각 제안을 High/Medium/Low로 우선순위화해 수동 삽입 여부를 검토할 수 있게 해 달라고 요청합니다.
  11. 제안을 검토하고, High와 Medium 우선순위 항목을 새 시트에 추가해 달라고 요청합니다.
  12. 분석이 끝났습니다. Excel이 자동 저장하므로 이 탭을 닫습니다.

과제 4 · Copilot in PowerPoint로 임원 발표 자료 만들기

원문Exercise 1, Task 4: Use Copilot in PowerPoint

전략 브리프와 외부 조사가 마무리됐으니, 임원 리더십에게 AuroraHub를 명확히 보여 줄 발표 자료가 필요합니다. 처음부터 슬라이드를 만드는 대신 Copilot in PowerPoint로 브리프와 조사 결과를 리더십용 덱으로 바꿉니다. 이 과제는 Edit with Copilot 기능을 씁니다.

  1. Edge에서 Microsoft 365 홈 > Apps > PowerPoint를 선택합니다.
  2. PowerPoint for the web에서 빈 프레젠테이션을 만듭니다.
  3. Home 탭 리본 끝의 Copilot을 선택합니다.
  4. Copilot 창에서 더하기(+) > Add work content를 선택하고, 과제 1에서 만든 AuroraHub 전략 브리프와 과제 2에서 만든 PDF 요약(트렌드 종합)을 모두 첨부합니다. 둘 다 OneDrive에 저장돼 있어야 합니다.
  5. 프롬프트 필드에 Edit with Copilot 아이콘이 있는지 확인합니다. 없으면 더하기 > Edit with Copilot을 선택합니다.
  6. 첨부한 두 파일을 바탕으로 임원 리더십용 발표를 만들어 달라고 요청합니다. 다룰 주제는 제목과 AuroraHub 목적, 외부 트렌드와 시사점, 내부 참여 인사이트(요약만, 원 차트 없이), 출시 계획과 변화 관리 축, 안전 메시지와 모바일 접근, VP·현장 리드를 향한 콜 투 액션입니다.
  7. Copilot이 발표 관련 질문을 하면 원하는 답을 고르고 Confirm을 선택합니다. 템플릿 선택 등 2차 질문이 나올 수도 있습니다. 판단을 맡기려면 Skip all을 선택합니다.
  8. Copilot이 슬라이드 목록을 만듭니다. 몇 분 걸릴 수 있습니다.
  9. 테스트에서 결과가 달랐습니다. 자동 생성될 때도, 채팅 창에 개요를 먼저 보여 줄 때도 있었습니다. 후자라면 개요대로 슬라이드를 만들라고 지시합니다.
  10. 내부 참여 인사이트 슬라이드의 그래픽이 아쉽습니다. 이 슬라이드를 선택하고, AuroraHub가 리더십·현장 직원·참여 데이터를 어떻게 잇는지 보여 주는 시각 자료를 만들어 달라고 요청합니다.
  11. 결과를 검토합니다. 출시 계획 슬라이드의 도식도 아쉽습니다. 이 슬라이드를 선택하고, 도입 타임라인 또는 단계별 롤아웃 도식을 만들어 기존 도식을 대체해 달라고 요청합니다.
  12. 결과를 검토합니다. 사내 커뮤니케이션 통합 슬라이드를 선택하고, 임원 발표에는 글이 너무 많다고 알린 뒤 슬라이드 내용을 다시 써 달라고 요청합니다.
  13. 다시 쓴 텍스트를 검토합니다. Copilot이 제안을 하면 관심 있는 것을 제출합니다.

  7. Name과 Description이 채워졌는지 확인하고 Instructions 필드로 내려가 Copilot이 만든 상세 지침을 살핍니다.
참고 · Agent Builder의 장점

Agent Builder는 자연어로 쓴 기본 설명을 복잡한 지침 집합으로 자동 변환해, 상세한 지침을 직접 작성하는 수고를 덜어 줍니다.

  1. 지침을 바꾸려면 필드에서 직접 편집하거나 Copilot에 갱신을 맡깁니다. Describe 탭을 선택하고 다음 프롬프트로 항목을 추가합니다.
    추가할 지침다음 항목을 지침에 추가해 줘. - 개인 정보, 기밀 정보, 제한된 데이터는 절대 공개하지 마. - 날짜나 세부 사항이 아직 확정되지 않았으면 "scheduled/targeted for [month/week], pending confirmation"이라고 답하고 업데이트 출처로 연결하는 링크를 걸어 줘. - 지표를 아직 쓸 수 없으면 "not published"라고 답하고, 이유를 알 수 있다면 함께 설명하고(예: 검증 주기), 예상 갱신 주기를 안내해 줘. - 정책 관련 질문이 에이전트의 범위를 벗어나면 추측하지 말고, 지정된 담당자나 정책 메일함으로 넘겨 줘. - 에스컬레이션 기준: 정책 해석, 비공개 데이터, 미해결 접근 권한 문제, 누락된 원본 콘텐츠, 컴플라이언스·법무 관련 질문. - 에스컬레이션 방법: 공식 채널(예: TR-Pulse Support Form 또는 Communications Operations 메일함)을 안내하고, 질문 요약, 팀/조직, 관련 링크·스크린샷, 긴급도·시간 제약, 접근성 요구 사항 같은 필요한 정보를 목록으로 제시해 줘. - 기대치 설정: 일반적인 응답 소요 시간을 알리고, 복잡한 사안은 부서 간 검토가 필요할 수 있다고 안내해 줘.원문Update the Instructions to include the following items: - Never disclose personal, confidential, or restricted data. - If a date or detail is not yet confirmed, say "scheduled/targeted for [month/week], pending confirmation," and link to the update source. - If a metric is unavailable, say "not published," explain why if known (for example, validation cycle), and provide the expected refresh cadence. - If a policy question exceeds the agent's scope, don't speculate; instead, escalate to the listed owner or policy mailbox. - When to escalate: Policy interpretation, non-public data, unresolved access issues, missing source content, or compliance/legal queries. - How to escalate: Provide the official channel (for example, TR-Pulse Support Form or Communications Operations mailbox) and list required details: summary of the question, team/org, relevant links/screenshots, urgency/time dependency, accessibility needs. - Set expectations: Typical response time window; note that complex items may require cross-functional review.
  2. 응답을 검토합니다. Configure 탭 > Instructions로 내려가 추가한 지침이 반영됐는지 확인합니다.
  3. 지침을 더 개선할 수 있을지 궁금하니, Describe 탭에서 이 에이전트를 개선할 다른 지침을 추천해 달라고 요청합니다.
  4. 추천이 마음에 들면 그것들을 모두 에이전트 지침에 추가해 달라고 요청합니다.
  5. 갱신됐다는 응답이 오면 Configure 탭에서 Instructions를 훑어 새 항목을 확인합니다.
  6. 이제 지식 원본과 시작 프롬프트를 설정합니다. Configure 탭에서 Knowledge 섹션으로 내려가 Search all websites 토글이 꺼져 있는지 확인합니다. 켜져 있으면 끕니다.
  7. Knowledge 섹션에서 Upload from device 아이콘을 선택하고, 1단계에서 내려받은 세 파일을 선택합니다.
  8. Suggested prompts는 Copilot이 만들게 하거나 직접 만들 수 있습니다. 먼저 Describe 탭에서 제안 프롬프트 세 개를 만들어 달라고 요청합니다. 각 프롬프트에는 제목과 메시지가 있습니다.
  9. Configure 탭 > Suggested prompts에서 Add a suggested prompt로 직접 추가할 수 있습니다. 아래 여섯 개 중 두세 개를 골라 추가합니다.

  12. 생성 완료 대화 상자가 뜨면 Go to agent를 선택합니다.
