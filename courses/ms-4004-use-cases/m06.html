인사 업무에서 Copilot 활용하기

Excel·Outlook·Loop로 관리자 성과 데이터를 통찰로 바꿔 리더십에 전하고, Copilot Studio·Viva Engage·Researcher로 직원 셀프서비스를 구축하는 실습입니다.

코스 개요 · 임원 · 영업 · IT · 마케팅 · 재무 · 인사 · 운영 · 커뮤니케이션 · 고객 서비스 · 법무

원문을 함께 확인해 주세요

이 문서는 Microsoft Learn 코스 MS-4004: Empower your workforce with Microsoft 365 Copilot use cases의 인사 모듈을 한국어로 옮긴 자료입니다. 원문 랩은 영어로만 제공됩니다.

Microsoft 365 Copilot은 기능과 화면이 자주 바뀝니다. 이 문서는 2026년 9월 기준이므로, 정확한 내용은 각 단원 머리의 원문 링크를 눌러 최신 버전에서 확인해 주세요.

Copilot에 입력하는 프롬프트와 값은 원문 그대로 두었습니다. 번역하면 결과가 달라지므로 영어 표기 그대로 입력해 주세요.

화면 이미지와 원문 내용의 저작권은 Microsoft에 있습니다.

개요와 준비

원문Introduction

인사(HR) 부서는 직원 지원, 정책 관리, 참여 유도의 중심에 있습니다. 업무 환경이 바뀌면서 효율, 응답성, 데이터 기반 의사 결정에 대한 요구가 커지고 있습니다. Microsoft 365 Copilot은 AI로 HR 업무를 간소화하고 직원 경험을 개선하며 새로운 전략 역량을 엽니다.

이 모듈에서 하는 일

HR 담당자가 Microsoft 365 Copilot으로 업무를 간소화하고 더 전략적으로 일하는 방법을 실습합니다. 다음을 다룹니다.

  • 반복 업무 자동화 · 복리후생, 휴가, 승진, 전근 같은 반복 문의에 즉시 정확히 답합니다.
  • 데이터 기반 통찰 · Copilot in Excel로 관리자 성과 지표를 요약하고 팀 건강도를 시각화하며 패턴을 찾습니다.
  • 전략적 커뮤니케이션 · 설문 요약, 관리자 피드백, 정책 업데이트를 일관성 있게 작성합니다.
  • 직원 셀프서비스 · 직원이 정책과 전근 지원 정보를 스스로 찾도록 맞춤 Copilot 에이전트를 만듭니다.
  • 내부·외부 지식 연결 · 회사 데이터와 웹 정보를 종합해 폭넓게 지원합니다.

효과적인 프롬프트 네 요소

Copilot을 잘 쓰는 핵심은 프롬프트의 품질입니다. 좋은 프롬프트는 다음 네 요소로 이루어집니다. 이 모듈의 연습에서 프롬프트를 쓸 때 항상 이 네 요소를 염두에 두십시오.

요소뜻예시
Goal (목표)Copilot이 무엇을 하기를 원하는지 분명히 밝힙니다.“최신 프로젝트 업데이트를 요약한 불릿 3~5개를 만들어 줘.”
Context (맥락)왜 필요한지, 누구와 무엇이 관련되는지 배경을 줍니다.“Client X와의 ‘Phase 3+’ 브랜드 캠페인 회의용으로 준비해 줘.”
Sources (출처)어디에서 정보를 찾을지 지정합니다.“6월 이후 이메일과 Teams 대화를 중심으로 봐 줘.”
Expectations (기대)어조, 형식, 상세도 등 결과 전달 방식을 정합니다.“빠르게 파악할 수 있게 쉬운 표현으로 설명해 줘.”

사전 준비 · OneDrive에 파일 올리기

이 모듈의 프롬프트는 파일을 참조합니다. 먼저 실습에 필요한 파일을 모두 OneDrive에 올려 두어야 합니다.

중요

Microsoft 365 Copilot은 OneDrive에 저장된 파일만 다룰 수 있습니다. PC에 로컬로 저장된 파일은 Copilot이 접근하도록 OneDrive로 옮겨야 합니다.

  1. 테넌트 제공자가 준비한 가상 머신에 로컬 Administrator 계정으로 로그인합니다. 암호는 Pa55w.rd입니다.
  2. Windows 작업 표시줄에서 Microsoft Edge를 선택합니다.
  3. 주소창에 https://www.office.com을 입력합니다.
  4. Welcome to Microsoft 365에서 Sign in을 선택합니다.
  5. 로그인 화면에서 userx@yourtenant.onmicrosoft.com(테넌트 제공자가 알려 준 사용자 이름과 테넌트)을 입력하고 Next를 선택합니다.
  6. 암호 입력 화면에서 사용자 계정 암호(테넌트 제공자가 제공)를 입력하고 Sign in을 선택합니다.
  7. Stay signed in 메시지가 나오면 Don't show this again을 선택하고 Yes를 선택합니다.
  8. Microsoft 365에서 Apps를 선택하고, Apps 안에서 OneDrive를 선택합니다.
  9. OneDrive 왼쪽 위에서 +(새로 만들기) > File upload를 선택합니다.
  10. File Explorer에서 This PC > Local Disk (C:)로 이동해 ResourceFiles 폴더를 엽니다.
  11. ResourceFiles 폴더의 파일을 모두 선택하고 Open을 선택해 OneDrive에 올립니다.
  12. 업로드가 끝나면 화면 아래 가운데에 Uploaded 29 items to My files가 보입니다. Edge는 열어 둔 채 다음 작업으로 넘어갑니다.
참고

Copilot 제안 목록에 어떤 파일이 바로 안 보일 수 있습니다. 일부 Copilot 환경은 Most Recently Used (MRU) 목록의 파일만 참조하기 때문입니다. 해당 파일을 관련 Microsoft 365 앱에서 한 번 열면 자동으로 MRU 목록에 추가됩니다.

연습 1 · Microsoft 365 Copilot으로 관리자 통찰 전달

원문Exercise 1: Deliver manager insights

HR에서 데이터는 더 나은 결정과 건강한 팀으로 이어질 때 가치가 있습니다. 참여도, 이직률, 교육 이수, 성과 평가는 방대한 양을 만들어 내지만, 거기서 의미를 뽑아 리더에게 명확한 지침으로 전하는 일이 HR의 진짜 기여입니다. Microsoft 365 Copilot은 원자료를 실행 가능한 통찰로 바꿔, 담당자가 계산보다 해석과 맥락, 코칭에 집중하도록 돕습니다.

팁

이 연습에서 프롬프트를 쓸 때 개요에서 익힌 네 요소(Goal, Context, Sources, Expectations)를 계속 떠올리십시오.

시나리오

여러분은 직원 8,000명 규모의 글로벌 기술 회사 Contoso Ltd.의 HR 분석가입니다. 회사는 관리자 역량을 최우선 전략 과제로 삼았지만, 연례 참여도 설문에서 부서 간 격차가 크게 나타났습니다. 최고 인사 책임자(Chief People Officer)가 이끄는 경영진은 관리자에 대한 데이터 기반 모니터링을 도입하려 합니다. 여러분의 과제는 Microsoft 365 Copilot으로 관리자 수준 HR 데이터에서 통찰을 뽑고 요약해 관리자와 HR 리더십에 맞춤 제안을 전하는 것입니다.

작업 1 · Excel에서 핵심 관리자 지표 찾기

원문Exercise 1, Task 1: Identify key manager metrics

Contoso의 최고 인사 책임자 Holly Dickson이 관리자 수준의 성과·참여 지표가 담긴 스프레드시트를 주었습니다. 어떤 지표가 관리자의 강점을, 어떤 지표가 높은 이직률이나 낮은 교육 이수 같은 개선 지점을 드러내는지 찾아 달라고 요청했습니다. Copilot in Excel로 관리자 효과성을 보여 주는 핵심 지표를 탐색하고 요약합니다.

이 지표는 Contoso_HR_ManagerMetrics.xlsx 파일에 담겨 있으며 다음 열로 구성됩니다.

Manager Name · Department · Engagement Score (%) · Attrition Rate (%) · Training Completion (%) · Average Team Tenure (Years) · Internal Promotions (Past Year) · Performance Rating (1–5)
Copilot in Excel · 두 가지 방식

일반 프롬프트는 데이터에 대한 질문과 통찰을 얻을 때, Edit with Copilot은 데이터 정리·수식 추가·표 재구성처럼 워크시트를 직접 바꿀 때 씁니다. 이 작업은 Edit with Copilot과 기본 Auto 모델 선택기를 씁니다. Excel의 선택기는 모델을 정하며 Copilot Chat의 선택기(추론 깊이)와는 다른 설정입니다.

  1. Contoso_HR_ManagerMetrics.xlsx를 내려받아 OneDrive에 저장합니다.
  2. Microsoft 365 홈(https://www.microsoft365.com)에 로그인해 Apps > Excel을 선택합니다.
  3. Excel for the web에서 Upload a file을 선택해 Contoso_HR_ManagerMetrics.xlsx를 엽니다.
  4. Home 리본에서 Copilot을 선택합니다. 응답 모드는 Auto로 두고 Edit with Copilot 아이콘을 확인합니다. 없으면 더하기(+)로 선택합니다.
  5. 이 데이터셋을 요약하고 어떤 지표가 관리자 효과성을 가장 강하게 나타내는지 짚어 달라고 다음 프롬프트를 제출합니다.
참고

이 첫 프롬프트는 네 요소를 반영한 예시로 원문을 그대로 제공합니다. 이후 프롬프트는 직접 작성하되, 이 프롬프트를 본보기로 삼으십시오.

프롬프트Summarize the dataset in Contoso_HR_ManagerMetrics.xlsx and identify which HR metrics most strongly indicate manager effectiveness. This task is part of an HR review at Contoso to evaluate manager strengths and development opportunities, such as high attrition or low training completion. Use the columns provided in the file (Engagement Score, Attrition Rate, Training Completion, Average Team Tenure, Internal Promotions, Performance Rating). Present the results in a clear, concise table with actionable insights that can be included in a report.
  1. 새 시트의 결과를 검토합니다.
  2. Excel에서는 Copilot이 사용할 워크북에 있어야 합니다. Sheet1을 선택하고, engagement score가 70% 미만이면서 attrition rate가 15%를 넘는 관리자를 찾아 새 시트에 표시해 달라고 요청합니다.
  3. 결과를 검토합니다. 이 시트에 머문 채 마지막 정보 줄 뒤에 커서를 두고, 방금 찾은 관리자를 시각화해 달라고 요청합니다.
  4. 결과를 검토하고 Sheet1로 돌아갑니다. training completion과 performance rating 사이에 패턴이 있는지 판단해 새 시트에 표시해 달라고 요청합니다.
  5. 결과를 검토하고 Sheet1로 돌아갑니다. engagement, attrition, training을 고려해 관리자를 팀 건강도 순으로 매긴 표를 새 시트에 만들어 달라고 요청합니다.
  6. 결과를 검토하고 Sheet1로 돌아갑니다. 부서별 attrition rate 대 engagement score를 보여 주는 막대 차트를 새 시트에 만들어 달라고 요청합니다.
  7. 결과를 검토합니다.
  8. 다음 작업을 위해 Contoso_HR_ManagerMetrics.xlsx 탭을 열어 둡니다.

이 작업을 마치면 Contoso 전반의 관리자 성과와 참여를 요약한 관점과 팀 건강도의 핵심 지표를 확보합니다. 이 데이터셋은 작업 2에서 관리자별 보고서를 만드는 토대가 됩니다.

작업 2 · Excel에서 관리자 요약 보고서 만들기

원문Exercise 1, Task 2: Generate a Manager Summary report

작업 1에서 참여, 이직, 교육의 추세를 파악했습니다. 이제 관리자별로 더 깊이 분석해 실행 가능한 통찰을 뽑고 이를 Manager Summary 보고서에 담습니다.

  1. Contoso_HR_ManagerMetrics.xlsx가 Excel for the web에 열려 있어야 합니다. 열려 있으면 Copilot 창 위의 Starts a new chat 아이콘으로 새 대화를 시작합니다. 닫았다면 파일과 Copilot 창을 다시 엽니다.
  2. 필요하면 Sheet1을 선택합니다. 관리자 성과 데이터를 분석해 개선 제안을 주고, 잘하는 관리자와 개선 여지가 있는 관리자를 구분해 달라고 요청합니다. 각 관리자의 상위 강점 3개와 개선 영역도 요약해 새 시트에 표시하도록 합니다.
  3. 결과를 검토합니다. 이 시트에 머문 채, 높은 팀 성과와 가장 강하게 상관되는 지표를 강조한 새 시트를 만들어 달라고 요청합니다.
  4. 결과를 검토하고 2단계에서 만든 관리자 성과 시트로 돌아갑니다. training과 attrition의 패턴을 강조하는 새 시트를 만들어, 낮은 교육 이수가 높은 이직에 영향을 줄 수 있는 관리자를 찾아 달라고 요청합니다.
  5. 결과를 검토하고 관리자 성과 시트로 돌아갑니다. 이 시트를 PDF로 내보내 작업 3에서 리더십에 이메일로 보내고 작업 4의 계획 세션에서 씁니다. File > Export > Download as PDF(또는 Create PDF/XPS Document)를 선택합니다.
    • Download as PDF였다면 Export 창에서 Download를 선택합니다. PC의 Downloads 폴더에 저장되니 OneDrive로 복사합니다.
    • Create PDF/XPS Document였다면 File Explorer 창에서 OneDrive에 저장합니다.

작업 3 · Outlook으로 결과를 HR 리더십에 전달하기

원문Exercise 1, Task 3: Communicate findings in Outlook

앞에서 만든 관리자 성과 보고서는 각 관리자의 상위 강점 3개와 개선 영역을 짚습니다. 이 결과를 HR 상위 리더십에 명확하고 전문적으로 전달합니다.

  1. Microsoft 365 홈에서 Apps > Outlook을 선택합니다.
  2. Outlook on the web에서 새 이메일을 만들고, 앞 작업에서 OneDrive에 저장한 관리자 성과 파일을 첨부합니다.
  3. 본문에서 첨부 파일 옆의 Open Copilot(연필) 아이콘을 선택합니다.
  4. 프롬프트 필드에, 첨부한 Manager Summary 보고서를 바탕으로 Contoso의 HR Director에게 보낼 이메일 초안을 써 달라고 요청합니다. 최근 관리자 성과 지표, 강점, 개선 영역을 요약하고, 실행 가능한 제안과 표의 구체적 데이터 포인트를 담도록 합니다.
  5. 결과를 검토합니다. HR Director에게 보내는 만큼 더 간결하게 만들어 달라고 요청합니다.
  6. 갱신된 이메일을 검토합니다. Copilot이 새 버전(2 of 2)을 만들었습니다. 뒤 화살표로 1 of 2를 볼 수 있고, 앞 화살표로 최신 초안(2 of 2)으로 돌아갑니다.
참고

요청할 때마다 Copilot은 새 초안을 만듭니다. 이전 초안으로 이동해 그대로 두거나, 그 초안을 수정해 달라고 할 수 있습니다. 기본적으로 새 요청은 마지막 초안을 보는 상태에서 이루어집니다.

  1. 내용은 만족스럽지만 어조가 확실치 않으니, Copilot 창의 Change Tone에서 원하는 어조를 고릅니다.
  2. 결과를 검토합니다. 필요하면 어조와 길이를 바꿔 봅니다. 변경할 때마다 초안 번호가 바뀝니다.
  3. 뒤·앞 화살표로 이전 초안을 살펴봅니다. 쓸 초안을 정하면 그 초안을 표시한 상태에서 Keep it을 선택합니다.
  4. 결과를 검토합니다. 초안이 실제 본문에 삽입됩니다. 초안 삽입 뒤에도 Copilot으로 이메일을 계속 수정할 수 있습니다.
    • 실제 메시지를 수정할 때는 바꿀 부분(문장, 문단, 전체)을 먼저 선택해야 합니다.
    • 텍스트를 추가하려면 삽입할 위치에 커서를 둡니다.
    마지막 문단으로, Contoso의 관리 문화를 개선할 실행 가능한 통찰을 앞으로 잘 진행하겠다는 내용을 넣으려 합니다. 맨 끝에 넣으려고 마지막 문장이나 문단을 선택한 뒤 Open Copilot(연필) 아이콘을 선택합니다.
  5. Copilot 창에서 그 내용의 문단을 추가해 달라고 요청합니다.
  6. 결과를 검토합니다. Copilot이 해당 텍스트만 강조해 표시합니다. 계속 수정하거나 그대로 받아들일 수 있습니다. 마음에 들면 Keep it을 선택합니다.
  7. 결과를 검토합니다. 새 문단이 요청한 끝이 아니라 이메일 맨 앞에 삽입됩니다.
알아 둘 동작 · Keep it의 삽입 위치

현재 Keep it을 선택하면 Copilot이 생성한 텍스트를 커서 위치나 프롬프트에서 요청한 위치가 아니라 Outlook 편집기 내부의 고정 자리(메시지 본문 맨 위)에 넣습니다. 화면에는 요청한 위치에 보여 주지만 실제 삽입은 맨 위로 갑니다. 이 동작이 개선될 때까지는 삽입된 문단을 선택해 잘라내기(Ctrl+X) 한 뒤 원하는 위치에 붙여넣기(Ctrl+V)로 옮겨야 합니다.

  1. 이메일을 마지막으로 읽어 봅니다. 어조가 확실치 않으면 전체를 드래그해 선택하고 Open Copilot 아이콘을 선택합니다.
  2. Copilot 메뉴에서 Change Tone을 선택하고 원하는 어조를 고릅니다.
  3. 수정된 이메일을 검토합니다. 마음에 안 들면 다른 어조를 시도합니다.
  4. 새 초안을 검토합니다. 여전히 마음에 안 들면, 친근하고 자신감 있되 전문적으로 들리게 어조를 바꿔 달라고 요청합니다.
  5. 결과를 검토합니다. 만족스러우면 Keep it을 선택합니다. 초안 모드에서 나와 실제 이메일로 들어갑니다.
  6. Copilot이 원래 버전을 이 수정 버전으로 바꿉니다. 이메일이 완성됩니다. 원하면 본인 개인 이메일로 보내, 수신 여부와 첨부 문서를 확인합니다.

I felt a whole lot better about using the agent after running those tests.” — Chet F., Operations Coordinator
  1. 인용을 검토합니다. 만족스러우면 수정된 도입과 인용을 써서 공지 전체를 다시 써 달라고 요청합니다.
  2. 결과를 검토합니다. 테스트에서는 Copilot이 도입과 인용을 그대로 쓰지 않고 또 새로 바꾸기도 했습니다. 그러면 원래 제안한 도입 수정과 직원 인용을 그대로 써서 공지를 다시 써 달라고 명확히 요청합니다.
  3. 만족스러우면 Copilot 창 결과 끝의 +Add to post를 선택합니다.
  4. 게시물 창에 나타난 공지를 검토하고, 앞뒤의 불필요한 Copilot 대화체 문장(예: “You asked for a…”)을 지웁니다.
  5. 게시 전에 커뮤니티나 스토리라인을 선택해야 합니다. 이 작업 처음에 Adatum HR agent testing 커뮤니티를 만들었으므로 게시물 아래에 표시됩니다. Select a community or storyline이 보이면 선택해 그 커뮤니티를 고릅니다.
  6. Post 버튼을 선택합니다.
  7. Adatum HR agent testing 커뮤니티에서 방금 만든 게시물을 확인합니다.
팁

Viva Engage에서 Copilot은 작성 전과 작성 중(초안, 재작성, 톤·길이 코칭)에 가장 강합니다. 공지가 게시된 뒤에는 Copilot이 라이브 게시물을 직접 편집할 수 없으므로, 내용을 직접 수정해야 합니다. 대신 Copilot이 더 나은 문구를 제안하거나 자료를 만들어 주면 붙여 넣을 수 있습니다.

작업 3 · HR 셀프서비스 에이전트에 정책 질문하기

원문Exercise 2, Task 3: Ask the agent about HR policies

이번에는 승진으로 노스다코타주 Fargo로 전근하는 Adatum 직원 역할을 맡습니다. 이사 전에 어떤 전근 혜택이 있는지 확인하려고, 새로 공지된 HR Self-Service Assistant에 정책을 물어봅니다.

  1. 앞 작업에서 HR Self-Service Assistant가 열려 있어야 합니다. 없으면 Microsoft 365 홈에서 선택합니다.
  2. 에이전트와 대화를 시작해 전근 관련 질문을 합니다.
    • Adatum이 어떤 전근 비용을 부담하는지
    • 전근 중 임시 주거가 제공되는지
    • 전근 후 1년 안에 퇴사하면 상환 의무가 있는지
  3. 다음 주제 중 하나 이상에 대해서도 질문합니다.
    • 승진 기준과 절차
    • Adatum의 401(k) 매칭 프로그램
    • 개인·가족 휴가 신청 절차
    • 교육·자격 상환 기회
    • Code of Conduct 위반 시 징계 절차나 결과
    • 원격·하이브리드 근무 자격과 기대
  4. 에이전트가 정책 파일을 어떻게 인용·요약하는지 관찰합니다. 답변의 완결성과 명료성을 평가하고, 셀프서비스 정확도를 위해 Adatum이 업데이트해야 할 정책이 있는지 메모합니다.
  5. 지식 원본에 없는 주제도 하나 이상 질문합니다. 예:
    • What is the salary range for my role at Adatum, and how are annual merit increases determined?
    • How does Adatum’s annual performance review process work, and what performance rating scale does the company use?
  6. 지식 원본에 없는 질문에 에이전트가 어떻게 응답하는지 평가합니다.

작업 4 · Researcher 에이전트로 전근 정보 조사하기

원문Exercise 2, Task 4: Gather relocation insights with Researcher

노스다코타주 Fargo 사무실로 전근하면서 Fargo와 노스다코타·미네소타의 인근 지역 생활을 알아봅니다. 삶의 질, 주거, 통근, 여가, 교육 환경 등을 종합해 가족이 정착할 지역을 정하려 합니다. Researcher 에이전트로 최신 웹 데이터에 근거한 구조화된 분석을 얻습니다.

  1. HR Self-Service Assistant 상태에서 탐색 창의 에이전트 목록 중 Researcher를 선택합니다.
  2. 이 질의에는 Web 원본만 쓰도록 지정합니다.
  3. Fargo와 노스다코타·미네소타 양쪽의 반경 40마일 이내 모든 인근 지역을 분석하는 보고서를 요청합니다. 가장 최신 데이터를 쓰고, 삶의 질과 가족 친화성으로 도시 순위를 매기며 핵심 트레이드오프를 설명하고 비교 표로 요약하도록 합니다. 다음 요소를 포함합니다.
    • 주택 시장과 부담 가능성
    • 생활비
    • 가족 지향 편의
    • 의료와 안전
    • 생활양식과 커뮤니티 특성
    • 세금과 재정 고려 사항
    • Fargo까지 통근 시간
  4. Researcher의 분석 방향을 검토합니다. 괜찮으면 Go ahead라고 알려 줍니다.
  5. 결과를 검토합니다. Fargo와 반경 40마일 이내 지역의 공립·사립 고등학교 보고서를 요청합니다. 최신 데이터를 쓰고 모든 기준을 동등하게 두어 학교 순위를 매기며 비교 표로 요약하도록 합니다. 다음 요소를 포함합니다.
    • 경쟁력 있는 체육 프로그램
    • IB·AP 과정 접근성
    • 대학 진학 성과
    • 과외 활동의 폭
    • 학생-교사 비율
    • 졸업률
  6. 분석 방향을 검토하고 괜찮으면 Go ahead라고 알려 줍니다.
  7. 결과를 검토합니다. 최고의 지역과 학교가 얼마나 맞물리는지, 위치와 교육의 트레이드오프를 파악합니다. 지역 분석 상위 5개 도시와 학교 분석 상위 5개 학교를 비교하는 표를 요청하며 다음 열을 포함합니다.
    • City name
    • School name
    • City ranking
    • School ranking
    • Key highlights (affordability, amenities, academic strengths)
  8. 결과를 검토합니다. Researcher는 짧은 프롬프트로도 최신 웹 데이터에 근거한 철저하고 구조화된 분석을 냅니다. 조사, 비교, 의사 결정 지원이 필요한 거의 모든 주제에 같은 방식을 쓸 수 있습니다.
