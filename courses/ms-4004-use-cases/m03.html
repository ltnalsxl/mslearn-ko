Microsoft 365 Copilot으로 네트워크 현대화 프로젝트를 계획하고 위험을 식별하며 발표 자료를 만들고, 90일 기능 도입 캠페인을 커뮤니케이션부터 피드백 분석까지 이끄는 실습입니다. 원문 랩을 한국어로 옮기고 막히기 쉬운 지점에 설명을 덧붙였습니다.

원문을 함께 확인해 주세요

이 문서는 Microsoft Learn 랩 Empower your workforce with Microsoft 365 Copilot use cases의 IT 모듈(M03)을 한국어로 옮기고 설명을 덧붙인 자료입니다. 원문 랩은 영어로만 제공됩니다.

Microsoft 365 Copilot은 기능과 화면이 빠르게 바뀝니다. 이 문서는 2026년 9월 기준이므로 정확한 내용은 각 단원 머리의 원문 링크를 눌러 최신 상태로 확인해 주세요.

입력할 프롬프트는 원문 그대로 두었습니다. 한 글자만 달라도 결과가 달라지므로 영어 표기 그대로 입력하시면 됩니다.

화면 이미지와 원문 내용의 저작권은 Microsoft에 있습니다.

이 모듈에서 하는 일

두 연습으로 나뉩니다. 먼저 Boulder Innovations의 IT 디렉터가 되어 네트워크 현대화·보안 강화 프로젝트를 계획합니다. Copilot Chat으로 흩어진 자료에서 프로젝트 프레임워크를 세우고, Whiteboard로 위험을 브레인스토밍하며, PowerPoint로 경영진 발표 자료를 만듭니다. 이어 VanArsdel의 IT 매니저가 되어 90일 기능 인지 캠페인을 이끕니다. Chat으로 신규 기능을 파악하고, Viva Engage로 공지하고, 모범 사례 팁을 만들고, Surveys 에이전트로 설문을, Analyst 에이전트로 설문 분석을 수행합니다.

파일을 OneDrive에 올리기

이 랩의 프롬프트는 OneDrive에 있는 파일을 참조합니다. 실습 전에 필요한 파일을 모두 OneDrive에 올립니다. 이 준비 단계는 세 모듈에 공통입니다.

  1. 테넌트 공급자가 제공한 가상 머신에 로컬 Administrator 계정으로 로그인합니다. 암호는 Pa55w.rd입니다.
  2. 작업 표시줄에서 Microsoft Edge를 열고 주소 표시줄에 https://www.office.com을 입력합니다.
  3. Welcome to Microsoft 365에서 Sign in을 선택하고, 공급자가 준 사용자 이름(userx@yourtenant.onmicrosoft.com 형식)과 암호로 로그인합니다.
  4. Stay signed in이 나오면 Don't show this again을 선택하고 Yes를 선택합니다.
  5. Microsoft 365에서 Apps > OneDrive를 차례로 선택합니다.
  6. 왼쪽 위에서 +(추가) > File upload를 선택합니다.
  7. File Explorer에서 This PC > Local Disk (C:)로 이동해 ResourceFiles 폴더를 엽니다.
  8. 폴더 안의 파일을 모두 선택하고 Open을 선택해 올립니다. 완료되면 Uploaded 29 items to My files가 표시됩니다.
중요

Microsoft 365 Copilot은 OneDrive에 저장된 파일만 다룹니다. PC에 로컬로 저장한 파일은 Copilot이 접근할 수 있도록 OneDrive로 옮겨야 합니다.

파일이 추천 목록에 안 보일 때

일부 Copilot 환경은 Most Recently Used (MRU) 목록의 파일만 참조합니다. 파일이 목록에 나타나게 하려면 해당 Microsoft 365 앱에서 그 파일을 한 번 열면 자동으로 추가됩니다.

효과적인 프롬프트 네 요소

Copilot을 잘 쓰는 첫걸음은 프롬프트의 품질입니다. 좋은 프롬프트는 다음 네 요소를 갖춥니다.

Goal (목표)

Copilot이 무엇을 하기를 바라는지 분명히 밝힙니다. 예: “Generate three to five bullet points summarizing the latest project updates.”

Context (맥락)

왜 필요한지, 누가·무엇이 관련되는지 배경을 줍니다. 예: “Prepare these bullet points for a meeting with Client X about their ‘Phase 3+’ brand campaign.”

Sources (원본)

어디서 정보를 찾을지 지정합니다. 예: “Focus on emails and Teams chats since June.”

Expectations (기대)

어떤 형식·어조·상세도로 받을지 정합니다. 예: “Use simple language so I can get up to speed quickly.”

연습 1 · Microsoft 365 Copilot으로 IT 프로젝트 계획 간소화

원문Exercise 1: Streamline IT project planning with Microsoft 365 Copilot

IT 프로젝트는 기술 역량뿐 아니라 매끄러운 조율과 명확한 커뮤니케이션, 탄탄한 문서화를 함께 요구합니다. 이 연습에서는 Copilot을 일상 흐름에 넣어 계획과 실행을 어떻게 개선하는지 살펴봅니다.

팁

개요에서 다룬 프롬프트의 네 요소, 곧 Goal·Context·Sources·Expectations를 이 연습 내내 염두에 둡니다.

시나리오

당신은 Boulder Innovations의 IT 디렉터로, 회사의 디지털 인프라를 전환하는 핵심 과제를 이끕니다. 현재 네트워크는 하이브리드 근무, 안전한 데이터 접근, 고성능 협업 수요를 감당하기 어렵습니다. 노후 하드웨어 교체, 제로 트러스트 보안 적용, 전환 중 비즈니스 연속성 확보가 과제에 포함됩니다. 계획부터 보고까지 전 과정에서 Copilot Chat, Whiteboard의 Copilot, PowerPoint의 Copilot을 써서 협업과 커뮤니케이션을 간소화합니다.

과제 1 · Copilot Chat으로 프로젝트 프레임워크 정의

원문Exercise 1, Task 1: Use Copilot Chat to define the project framework

작업을 시작하기 전에 CIO는 프로젝트의 목적·목표·산출물·이해관계자를 분명히 알고 싶어 합니다. 프로젝트 문서, 이메일 스레드, 채팅 로그에서 관련 정보를 모아 하나의 프로젝트 프레임워크로 종합합니다. Copilot Chat이 흩어진 데이터를 잇는 다리 역할을 합니다.

참고 · BYOS 환경

이 코스는 자체 구독(BYOS) 모델이라 Boulder Innovations용 시뮬레이션 랩 환경이 없습니다. 그래서 이메일은 Word(.docx) 파일로, Teams 채팅은 텍스트(.txt) 파일로 대체합니다. Copilot Chat은 이 내용을 실제 이메일·채팅처럼 읽고 요약할 수 있습니다. 이 과제는 Work 모드를 쓰므로 응답 모드 선택기는 적용되지 않습니다.

  1. 다음 파일을 모두 내려받아 OneDrive에 저장합니다. Network Modernization and Security Upgrade 프로젝트를 다룬 가상 이메일·채팅·문서입니다.
    • BI Project Proposal Draft.docx
    • BI Email Thread – Budget Discussion.docx
    • BI Teams Chat Export.txt
    • BI Meeting Notes – Stakeholder Brief.docx
    • BI Email – Vendor Quote Summary.docx
    • BI Security Risk Memo.docx
  2. Microsoft Edge에서 Microsoft 365 홈(https://www.microsoft365.com)에 로그인합니다.
  3. Microsoft 365 Copilot Chat에서 Work 탭이 선택됐는지 확인하고, 내려받은 파일을 모두 첨부합니다. 다음 프롬프트를 씁니다.
참고

이 첫 프롬프트는 네 요소를 어떻게 담는지 보여 주려고 본문을 그대로 제공했습니다. 나머지 프롬프트는 직접 작성하되, 이 프롬프트를 본보기로 삼으면 됩니다.

프롬프트첨부한 문서를 활용해서 Boulder Innovation의 'Network Modernization and Security Upgrade' 프로젝트를 요약해 줘. 목적과 범위, 주요 목표, 핵심 산출물, 마일스톤, 위험 요인, 이해관계자를 다루는 경영진용 요약 프레임워크를 간결하게 만들어 줘. 출처(파일명과 날짜)를 표시하고, 서로 어긋나는 내용이 있으면 짚어 줘. 요약은 짧은 섹션과 글머리 기호로 정리하고, 마지막에 각 섹션과 출처를 연결한 부록도 붙여 줘.원문Summarize Boulder Innovation’s ‘Network Modernization and Security Upgrade’ project using the attached documents. Create a concise framework for leadership that covers: purpose and scope, top objectives, key deliverables, milestones, risks, and stakeholders. Cite your sources (file names and dates) and note any conflicting details. Present the summary in short sections and bullet points, followed by an appendix that maps each section to its sources.
  1. 결과를 검토하고, CIO와 공유할 수 있게 서식이 잡힌 Word 문서로 만들어 달라고 요청합니다.
  2. 생성된 문서를 내려받아 Downloads 폴더에서 OneDrive 폴더로 옮깁니다.
  3. Word에서 파일을 열어 요청한 정보가 모두 들어 있는지 확인합니다.
  4. Home 탭 리본에서 Copilot을 선택하고 Edit with Copilot 아이콘이 보이는지 확인합니다. 없으면 플러스를 선택해 활성화합니다.
  5. 문서 일부 섹션을 보완할 이미지·차트·SmartArt 그래픽을 제안해 달라고 요청합니다.
  6. 제안 중 하나를 골라 그 이미지를 생성해 달라고 요청합니다.
참고

이미지 생성에는 시간이 걸리므로 요청은 이미지 하나로 제한합니다.

  1. Agent Mode(버전에 따라 Edit with Copilot)가 켜진 상태에서 이미지를 만들거나 삽입할 수 없다고 하면, 프롬프트 입력란의 Edit with Copilot 아이콘을 선택해 그 모드를 빠져나온 뒤 다시 이미지 생성을 요청합니다.
  2. 이미지를 넣을 위치에 커서를 둡니다. Copilot 창에 이미지가 생성되면 이미지 위로 마우스를 올려 나타나는 플러스(+)를 선택해 커서 위치에 삽입합니다.
  3. 이미지 생성을 위해 Edit with Copilot 모드를 빠져나왔다면, 플러스를 선택하고 드롭다운에서 Edit with Copilot을 선택해 다시 그 모드로 돌아갑니다.
  4. 문서 끝에 커서를 두고, 문서 내용을 바탕으로 잠재 질문과 답변을 담은 Q&A 섹션을 추가해 달라고 요청합니다.
  5. 삽입된 Q&A가 기존 불릿을 되풀이하는 수준이면, 더 깊이 생각하게 하고 가정을 되짚으며 프로젝트를 넓은 맥락과 잇는 다른 질문·답변을 만들어 달라고 요청합니다.
  6. 보강된 Q&A를 검토합니다. Copilot 창 끝의 추천 프롬프트 중 관심 있는 것이 있으면 지금 제출합니다.
  7. 이 문서는 과제 3의 경영진 발표 자료 기반이 되므로 OneDrive의 파일 이름을 확인해 둡니다.

과제 2 · Copilot in Whiteboard로 잠재 위험 식별

원문Exercise 1, Task 2: Use Copilot in Whiteboard to identify potential risks

계획 단계로 들어서면서 일정·예산·보안·운영에 영향을 줄 위험을 식별합니다. 이 과제는 AI가 돕는 스티커 메모 브레인스토밍입니다. 사람 대신 Copilot이 아이디어를 만들어 노란 스티커 메모로 캔버스에 붙이고, 사용자는 편집·삭제하며, 마지막에 Copilot이 카테고리로 묶습니다.

  1. Microsoft 365 Copilot Chat 창에서 Apps 아이콘을 선택하고 All apps > All apps→로 들어가 아래로 스크롤해 Whiteboard를 선택합니다.
  2. Whiteboard for the web에서 새 세션을 시작합니다.
  3. Board name은 기본값 Whiteboard X입니다. 이 필드를 선택해 Project Risks – Network Modernization으로 바꿉니다.
  4. 아래 메뉴 막대 옆의 Copilot 아이콘을 선택하고 Suggest를 선택합니다.
  5. Suggest content with Copilot 창에서, 성능 개선·사이버 보안 강화·하이브리드 근무 지원을 위해 회사 네트워크 인프라를 업그레이드할 때의 잠재 위험 목록을 제안해 달라고 요청합니다.
  6. Copilot은 기본으로 여섯 개씩 아이디어를 만듭니다. 만족스러우면 붙이거나 Generate more로 더 만듭니다. Insert (N) 단추의 숫자가 만들어진 아이디어 수입니다. 위험을 최소 18개 이상 만든 뒤 캔버스에 삽입합니다.
  7. Copilot이 아이디어를 노란 스티커 메모로 붙입니다. 메모를 더블클릭하면 위쪽 메뉴 막대에서 Edit text(연필) 아이콘이나 줄임표 메뉴로 편집·삭제할 수 있습니다. 자유롭게 편집합니다.
  8. 네트워크 다운타임 관련 위험이 적다면, Copilot 아이콘을 선택하고 Suggest를 선택합니다.
  9. 시스템 다운타임과 관련된 위험을 제안해 달라고 요청합니다.
  10. 다운타임 관련 위험 여섯 개를 삽입합니다. 여섯 개 묶음은 선으로 둘러싸인 노트 그리드가 됩니다. 기존 메모와 겹치면 그리드 테두리를 잡아 옆으로 옮깁니다. 화면 밖으로 넘어가면 오른쪽 아래 Fit to Screen 아이콘을 필요한 만큼 선택합니다.
  11. 지우고 싶은 메모를 선택하고, 아이콘 트레이의 줄임표에서 Delete를 선택합니다.
  12. 편집을 마쳤으면 Copilot이 메모를 카테고리별로 정리하게 합니다. Copilot이 카테고리 이름을 정하고 메모를 배치합니다.
주의

메모 분류를 선택하면 Whiteboard는 현재 화면에 보이는 스티커 메모만 테두리 안에 선택합니다. 화면 밖 메모는 포함되지 않으므로, 바로 진행하면 테두리 밖 메모는 분류되지 않습니다.

  1. 모든 메모를 테두리 안에 넣는 두 가지 방법이 있습니다.
    • 화면에 더 많은 메모 표시 · 확대·축소하거나 이동해 원하는 메모가 모두 보이게 합니다.
    • 키보드로 모두 선택 · Ctrl+A로 화면 밖 메모까지 캔버스의 모든 개체를 선택합니다.
    이 과제에서는 Ctrl+A로 모든 메모를 선택합니다.
  2. 일부 메모가 화면에 다 보이지 않으면 테두리 가장자리를 잡아 전체 선택을 캔버스 안으로 끌어옵니다.
  3. 모든 메모가 보이는 상태에서 Copilot 아이콘을 선택하고 Categorize를 선택합니다. Categorize selected notes 창에서 Categorize 단추를 선택합니다.
  4. Copilot이 카테고리를 만들고 메모를 재배치하며 각 카테고리에 색을 입힙니다. 상자가 작아 읽기 어려우면 Fit to Screen 아이콘을 씁니다.
  5. 카테고리가 마음에 들지 않으면 아이콘 트레이의 Regenerate 단추를 선택합니다.
팁

Regenerate는 만족할 때까지 몇 번이고 선택할 수 있습니다. 매번 카테고리 이름과 메모 배치가 바뀌고, 카테고리 수가 늘거나 줄기도 합니다.

  1. 여러 번 재생성한 뒤 어느 결과가 나은지 모르겠다면, Copilot은 이전 분류로 되돌아가지는 못하지만 처음부터 다시 시작할 수는 있습니다. Revert 단추로 노란 스티커 메모 목록으로 되돌립니다.
  2. 다시 분류하려면 Copilot 아이콘 > Categorize를 선택하고 Categorize 단추를 선택합니다.
  3. 시간을 아끼기 위해 Regenerate를 한두 번만 선택해 결과에 만족합니다.
  4. 브레인스토밍 요약을 화이트보드에 추가하려면 Copilot 아이콘을 선택하고 Summarize를 선택합니다.
  5. 이 요약을 다음 과제의 PowerPoint 자료에 넣을 수 있게 Word로 저장합니다. Summary 창의 텍스트를 선택해 복사(Ctrl+C)하고, 빈 Word 문서에 붙여 넣어 OneDrive에 저장한 뒤 화이트보드로 돌아갑니다.

과제 3 · Copilot in PowerPoint로 경영진 발표 자료 만들기

원문Exercise 1, Task 3: Use Copilot in PowerPoint to create an executive presentation

CIO가 네트워크 현대화 프로젝트의 현황, 핵심 마일스톤, 위험, 다음 단계를 브리핑해 달라고 요청했습니다. 과제 1의 프로젝트 계획과 과제 2의 위험 분석을 Copilot in PowerPoint로 경영진용 발표 자료로 바꿉니다. 이 과제는 Edit with Copilot 기능을 씁니다.

  1. Microsoft Edge에서 Microsoft 365 홈으로 이동해 Apps > PowerPoint를 선택합니다.
  2. PowerPoint for the web에서 빈 프레젠테이션을 만듭니다.
  3. Home 탭이 안 보이면 선택하고, 리본 끝의 Copilot을 선택합니다.
  4. Copilot 창에서 플러스(+)를 선택하고 Add work content를 선택해 과제 1·2에서 만든 Word 파일을 첨부합니다.
  5. Edit with Copilot 아이콘이 보이는지 확인하고, 없으면 플러스를 선택해 활성화합니다.
  6. 두 파일의 핵심 정보를 요약하는, Network Modernization 프로젝트용 경영진 발표 자료를 만들어 달라고 요청합니다.
  7. Copilot이 질문을 하면 원하는 답을 고르고 Confirm을 선택합니다. 슬라이드 템플릿 선택 같은 두 번째 질문이 이어질 수 있습니다. 템플릿을 고르지 않으면 흰 슬라이드에 텍스트만 나오므로, 원하는 답을 고르거나 판단을 맡기려면 Skip all을 선택합니다.
  8. Copilot이 슬라이드 목록을 생성합니다. 몇 분 걸릴 수 있습니다.
  9. 토론 슬라이드 세 개를 추가합니다. 인프라·현대화 프로젝트에서 임원과 CIO의 3대 관심사입니다. 슬라이드를 덱 끝에 넣기 위해, 왼쪽 슬라이드 창에서 맨 아래로 스크롤해 마지막 슬라이드 뒤를 선택합니다.
    • Operational and business continuity risk
    • Security, compliance, and data protection
    • Budget, value, and delivery confidence
  10. Discussions: Risk, Security, and Value 제목의 주제 섹션 슬라이드를 추가하고, 그 아래 위 세 주제로 슬라이드를 각각 하나씩 넣어 달라고 요청합니다.
  11. 덱 끝으로 스크롤해 새 주제와 세 토론 슬라이드가 추가됐는지 확인합니다. 각 슬라이드의 기존 내용을 아래 논점으로 바꿔 달라고 요청합니다.
    • Operational and business continuity risk · 다운타임·서비스 중단 예상 여부, 견고한 비상·롤백 계획 유무, 고객·직원 영향 최소화 방안
    • Security, compliance, and data protection · 기술 변경으로 생기는 새 취약점, 규제 준수(데이터 프라이버시·업계 표준), 사고 탐지·대응·복구 역량
    • Budget, value, and delivery confidence · 비용 초과와 숨은 지출, 지연과 마일스톤 미달, 측정 가능한 성과와 ROI
  12. 세 슬라이드가 요청대로 바뀌었는지 확인하고, 채팅 끝의 제안 중 관심 있는 변경을 자유롭게 요청합니다.
  13. 만족스러우면 PowerPoint 파일을 OneDrive에 저장합니다.

과제 1 · Copilot Chat으로 신규 Microsoft 365 기능 파악

원문Exercise 2, Task 1: Use Microsoft 365 Copilot Chat to identify upcoming Microsoft 365 features

IT 리더십 회의를 앞두고, 다음 90일 안에 사용자에게 영향을 줄 신규 Microsoft 365 기능을 요약합니다. 예전에는 블로그와 관리 센터를 뒤져 몇 시간이 걸렸지만, Copilot Chat으로 약 1분 만에 정리합니다. 이 과제는 기본값 Auto 선택기를 씁니다.

  1. Microsoft Edge에서 Microsoft 365 홈(https://www.microsoft365.com)에 로그인합니다. 이 정보는 Microsoft가 공개하는 향후 기능이라 테넌트에 없으므로 Work가 아닌 Web 옵션을 선택하고, 선택기는 Auto로 둡니다.
  2. 다음 프롬프트를 복사해 붙여 넣습니다.
참고

이 첫 프롬프트는 네 요소를 어떻게 담는지 보여 주려고 본문을 그대로 제공했습니다. 나머지 프롬프트는 직접 작성하되, 이 프롬프트를 본보기로 삼으면 됩니다.

프롬프트나는 VanArsdel, Ltd.의 IT 관리자야. 앞으로 90일 안에 Microsoft가 출시하거나 정식 출시할 예정인 Microsoft 365 기능 중에서 최종 사용자와 가장 관련이 깊은 것들(예: 협업, 보안, Teams, Outlook, SharePoint, Viva 등)을 요약해 줘. 각 기능마다 한 줄 설명, 비기술 사용자에게 왜 중요한지, IT 부서가 취할 만한 조치(예: 공지, 교육, 테넌트 설정 변경)를 함께 정리해 줘. 결과는 8개 이하의 짧은 글머리 목록으로 만들어 줘.원문I'm the IT Manager at VanArsdel, Ltd. Summarize the Microsoft 365 features likely to be released or generally available by Microsoft in the next 90 days that are most relevant to end users (such as collaboration, security, Teams, Outlook, SharePoint, Viva, and so on). Please list each feature along with the following information: a one-line description, why it matters for a non-technical end user, and any recommended action for IT (for example, communication, training, and change to tenant settings). Provide the result as a short bullet list (no more than 8 items).
  1. 응답을 검토합니다. 출처가 있으면 몇 개를 확인하고, 모호한 항목은 후속 질문으로 명확히 합니다.
  2. 응답 끝에서 Edit in Pages 아이콘을 선택합니다.
  3. Pages 폼에서 Create를 선택하고 Document를 선택합니다. 대화 상자에서 Open Word를 선택해 Word for the web에서 엽니다.
  4. Copilot이 응답 전체를 문서에 복사합니다. 앞뒤의 군더더기 채팅 텍스트를 지우고, 커뮤니케이션에서 우선할 항목을 태그하거나 강조합니다.
  5. Home 탭에서 Copilot을 선택하고 Edit with Copilot 아이콘이 보이는지 확인합니다. 없으면 플러스를 선택해 활성화합니다.
  6. 요약을 넣을 위치, 곧 문서 제목과 기능 목록 사이에 커서를 둡니다.
  7. 문서 내용을 바탕으로 짧은 경영진 요약을 추가해 달라고 요청합니다.
  8. 이어 각 기능마다 위험 또는 기회를 한 문장씩 추가해 달라고 요청합니다.
  9. 위험·기회가 별도 섹션으로 붙었다면, 그 섹션을 지우고 대신 각 기능 끝에 위험 또는 기회를 넣어 달라고 요청합니다.
  10. 새 내용의 서식이 마음에 들지 않으면 원하는 대로 조정합니다.
  11. 이 문서는 과제 3에서 쓰므로 파일 이름을 확인해 둡니다.

과제 2 · Copilot in Viva Engage로 신규 기능 게시글 초안

원문Exercise 2, Task 2: Use Copilot in Viva Engage to draft a post about upcoming features

CIO가 신규 기능에 대한 관심을 끌어올리고 싶어 합니다. VanArsdel은 사내 공지에 Viva Engage를 쓰므로, Copilot in Viva Engage로 상위 세 개 기능을 강조하는 공지 게시글을 만듭니다. 어조는 친근하고 접근하기 쉽게 하되 지나치게 기술적이지 않게 하고, 피드백이나 데모 참여를 권합니다.

  1. Microsoft 365 Copilot Chat 창에서 Apps 아이콘 > All apps > All apps→로 들어가 아래로 스크롤해 Viva를 선택합니다.
  2. Viva for the web에서 탐색 창의 Engage를 선택합니다.
  3. 먼저 테스트용 커뮤니티를 만듭니다. Engage 탐색 창 위의 +Create new를 선택하고 Community를 선택합니다.
  4. Create a new community 창의 Name 필드에 Copilot testing을 입력합니다.
중요

본인 테넌트를 쓰므로 만든 Viva Engage 커뮤니티는 테넌트의 다른 사용자에게도 보입니다. 혼란을 피하려고 Microsoft 365 feature rollout 같은 이름 대신 Copilot testing을 커뮤니티 이름으로 씁니다.

  1. Description 필드에 This community is used for testing Copilot training content을 입력하고 Create를 선택합니다.
  2. +Create new를 선택하고 Post를 선택합니다.
  3. Post 창에서 Copilot 아이콘을 선택해 Copilot 창을 엽니다.
  4. 프롬프트 입력란에 앞 과제의 Word 문서를 첨부합니다. 그 문서에 담긴 신규 Microsoft 365 기능을 알리는 VanArsdel용 Viva Engage 공지를 초안으로 만들어 달라고 요청합니다. 어조는 친근하고 간결하게, 전 직원 대상이라 지나치게 기술적이지 않게 합니다. 짧고 눈길을 끄는 헤드라인, 상위 세 개 불릿(각 기능이 무엇이고 어떻게 돕는지), 기능을 써 보거나 짧은 데모에 참여하라는 한 문장 행동 유도, 짧은 설문(플레이스홀더 링크)으로 피드백 요청, 추천 해시태그와 이모지 한둘을 포함하게 합니다.
  5. 생성된 내용을 검토하고 결과 끝의 +Add to post를 선택합니다. 앞뒤의 군더더기 Copilot 채팅 텍스트(예: “You asked for a…”)를 지웁니다.
  6. 게시하려면 커뮤니티나 스토리라인을 골라야 합니다. 과제 시작에서 만든 Copilot testing 커뮤니티가 게시 창 아래에 보이면 다음 단계로 넘어갑니다. 대신 Select a community or storyline 옵션이 보이면 그것을 선택하고 Copilot testing 커뮤니티를 고릅니다.
  7. Post 단추를 선택합니다.
  8. Copilot testing 커뮤니티에서 Copilot이 만든 게시글을 확인합니다.

과제 3 · Copilot Chat으로 모범 사례 팁 만들기

원문Exercise 2, Task 3: Use Microsoft 365 Copilot Chat to create best practice tips

사용자가 신규 기능을 매끄럽게 받아들이도록 교육·온보딩에 쓸 치트 시트를 만듭니다. 앞서 조사한 기능을 바탕으로, 직원이 자신 있게 쓰도록 돕는 짧고 실행 가능한 모범 사례 팁 10개를 만듭니다.

    • 이메일용 버전(짧은 제목 줄 + 불릿 5개)
  5. 생성된 Word 문서와 PDF를 내려받아 각 파일 내용을 검토합니다.
  6. Executives, Sales, IT에 맞춘 별도 버전이 좋겠다는 판단에 따라, 페르소나별 치트 시트를 PDF로 각각 생성해 달라고 요청합니다.
  7. 각 PDF를 내려받아 페르소나별 문서의 차이를 확인합니다.

과제 4 · Surveys 에이전트로 피드백 설문 만들기

원문Exercise 2, Task 4: Use the Surveys agent to create a feedback survey

기능 배포 한 달 뒤, CIO가 직원 반응을 알고 싶어 합니다. 짧은 사내 설문으로 도입과 만족도를 측정합니다. Surveys 에이전트로 질문 유형과 구조, 분기 로직을 설계합니다. 목표는 5개 척도 문항과 3개 개방형 문항으로 이뤄진 8문항 설문입니다.

  1. Microsoft 365 홈에서 All agents를 선택하고 사전 제작 에이전트 목록에서 Surveys 에이전트를 선택합니다.
  2. 새 설문을 만들어 달라고 요청합니다. 과제 1의 기능 문서를 첨부하고 다음을 포함하게 합니다.
    • 한 문장 소개
    • 8문항: 정량 5개(리커트 척도, 객관식), 개방형 3개
    • 분기 규칙: 도입 관련 문항에 “No”로 답하면, 도입하지 않은 이유를 묻는 후속 개방형 문항 제시
  3. 부서를 묻는 인구통계 문항 하나를 넣어 달라고 요청합니다. 리커트 척도 문항에 1~5 각 값의 설명이 없으면, 예컨대 1이 Very difficult, 5가 Very easy일 때 2~4에도 설명을 넣어 달라고 합니다.
  4. 만족스러우면 Copilot 아이콘을 선택해 응답을 복사합니다.
  5. 복사한 설문을 Microsoft Forms에 붙여 넣습니다. Microsoft 365 Copilot Chat 창에서 Apps > All apps > All apps→로 들어가 Forms를 선택합니다.
  6. 새 폼을 만들고 Draft with Copilot 창에 복사한 설문을 붙여 넣어 제출합니다.
  7. 결과를 검토합니다. draft 1 of 1이므로 만족스러우면 Keep it을 선택하거나, 다른 변경을 요청한 뒤 원하는 초안에서 Keep it을 선택합니다.
  8. Copilot이 폼에 대한 다른 제안을 제시하면 살펴봅니다. 예컨대 테마 현대화 제안을 선택해 테마를 고르고 변경을 확인한 뒤 유지하거나 버립니다.

과제 5 · Analyst 에이전트로 설문 결과 분석

원문Exercise 2, Task 5: Use the Analyst agent to analyze survey results

설문 결과가 모였습니다. Analyst 에이전트로 추세를 찾고 도입 지표를 시각화하며 요약 보고서를 만듭니다. 목표는 차트 3개, 5개 불릿 경영진 요약, 도입 개선을 위한 IT 권고 목록입니다.

참고

이 시나리오를 위해 Surveys 에이전트가 만든 8문항에 대한 직원 응답 스프레드시트를 준비했습니다. 실습용 가상 응답 500건이 담겨 있습니다.

  1. 다음 링크에서 VanArsdel M365 Survey Results.xlsx 파일을 내려받아 OneDrive에 저장합니다.
  2. 스프레드시트를 열어 결과를 검토합니다. 열 너비를 넓혀야 답변이 다 보일 수 있습니다. 검토 후 닫습니다.
  3. Copilot Chat으로 돌아가 탐색 창에서 Analyst 에이전트를 선택합니다.
  4. Analyst 에이전트에 VanArsdel M365 Survey Results.xlsx를 첨부합니다.
  5. 첨부한 직원 설문 결과를 분석해 다음을 제공해 달라고 요청합니다.
    • 5개 불릿 경영진 요약(긍정 상위 3, 우려 상위 2)
    • 차트 3개: 부서별 도입률, 사용 편의성 점수 분포, 주요 걸림돌 빈도
    • 우선순위를 매긴 IT 권고 5개(빠른 성과 우선)
    • 통계적으로 유의한 패턴(있다면)
  6. 결과를 검토합니다. 추천 프롬프트가 있으면 관심에 따라 제출합니다.
  7. 데이터에서 끌어낼 수 있는 상관관계가 있는지 물어봅니다.
  8. 응답을 검토하고, 상관관계 관련 추천 프롬프트가 있으면 제출합니다.
  9. IT 부서 소속이므로 IT 부서 응답이 궁금하다면, 데이터를 IT 부서 응답만 보이게 필터링해 달라고 요청합니다.
  10. 응답을 검토하고, IT 응답 관련 추천 프롬프트가 있으면 제출합니다.
  11. 마지막으로 다운로드할 수 있는 한 페이지 경영진 요약 보고서와, 통찰·차트를 모두 담은 정돈된 경영진 슬라이드 덱을 만들어 달라고 요청합니다.
  12. 다운로드 관련 추천 프롬프트가 있으면 자유롭게 제출합니다.
  13. 요약 보고서와 슬라이드 덱을 내려받아 각 문서를 검토합니다.
