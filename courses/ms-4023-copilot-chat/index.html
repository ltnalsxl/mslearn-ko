Microsoft 365 Copilot Chat 살펴보기

중견 컨설팅 회사의 운영 담당자가 되어 고객 혁신 서밋을 기획합니다. Microsoft 365 Copilot Chat 웹 모드로 동향을 조사하고, 아이디어를 만들고, 일정을 시각화하고, 문서를 작성하고, 동료와 협업하는 과정을 따라갑니다.

태스크 6개 선택 마무리 1개 웹 모드 수준 100
원문을 함께 확인해 주세요

이 문서는 Microsoft Learn 실습 랩 Explore Microsoft 365 Copilot Chat를 한국어로 옮기고 설명을 덧붙인 자료입니다. 원문 랩은 영어로만 제공됩니다.

Copilot Chat은 기능과 화면이 빠르게 바뀝니다. 이 문서는 2026년 9월 기준이므로, 정확한 내용은 아래 원문 링크를 눌러 최신 상태로 확인해 주세요.

프롬프트와 입력값은 원문 그대로 옮겼으니 영어 표기 그대로 입력하시면 됩니다.

화면 이미지와 원문 내용의 저작권은 Microsoft에 있습니다.

원문Lab 1 - Plan a Client Summit with Microsoft 365 Copilot Chat
이 랩에서 하는 일

Copilot Chat 하나로 조사, 아이디어 도출, 시각화, 문서 작성, 요약, 협업까지 이어 갑니다. 이 랩을 끝까지 완료하려면 Microsoft 365 구독이 필요합니다.

웹 모드로 전환하세요

이 태스크는 Microsoft 365 Copilot Chat의 웹 모드(web mode)에 맞춰 설계됐습니다. Microsoft 365 Copilot 라이선스가 있으면 Copilot Chat이 작업 모드(work mode)로 먼저 열릴 수 있으므로, 열 때 직접 웹 모드로 전환하세요. 웹 모드라야 프롬프트가 의도대로 동작하고 공개 웹 콘텐츠를 근거로 답합니다.

시작하기 전에

랩을 시작하려면 가상 머신에 로그인해 Microsoft 365 Copilot Chat 웹 앱을 실행합니다.

  1. 테넌트 공급자가 제공한 가상 머신에 로컬 Administrator 계정으로 로그인합니다. 암호는 Pa55w.rd입니다.
  2. Windows 작업 표시줄에서 Microsoft Edge를 선택합니다.
  3. Microsoft 365 Copilot Chat을 실행하려면 주소 표시줄에 https://m365copilot.com을 입력합니다. 로그인 대화 상자가 나타납니다.
  4. Sign-in Prompt에 userx@yourtenant.onmicrosoft.com(테넌트 공급자 제공)을 입력하고 Next를 선택합니다.
  5. Enter password 화면에서 Password1(테넌트 공급자 제공)을 입력하고 Sign in을 선택합니다.
  6. Stay signed in?이 나오면 Don't show this again 확인란을 선택하고 Yes를 선택합니다.
  7. Unlock Copilot Chat in Microsoft 365 Apps 안내가 나오면 Skip for now나 Add Copilot 중 무엇을 선택해도 됩니다. 이 선택은 실습에 영향을 주지 않습니다.
  8. Microsoft 365 Copilot Chat 웹 앱이 실행됩니다. 실행되지 않으면 왼쪽 탐색 메뉴의 Copilot 아이콘을 선택해 Copilot Chat을 엽니다.

태스크 1 · 업계 동향 요약

Copilot Chat이 웹에서 서밋과 관련된 핵심 혁신 동향을 빠르게 찾아 주는 방법을 살펴봅니다. 여기서 정리한 동향이 고객의 관심사에 맞는 의제를 짜는 토대가 됩니다.

  1. Copilot Chat 아래쪽 프롬프트 상자에 다음 프롬프트를 입력합니다.
프롬프트2025년 [your industry] 분야에서 가장 주목할 만한 혁신 트렌드 3가지는 무엇이고, 이 트렌드가 고객 서밋의 의제를 어떻게 정할 수 있는지 알려 줘.원문What are the top three innovation trends in [your industry] for 2025 and how can they shape the agenda for a client summit?
참고

[your industry] 부분을 원하는 업계 이름으로 바꿔 입력합니다.

  1. 프롬프트 상자 오른쪽 아래의 Send(화살표 아이콘)를 선택하거나 키보드에서 Enter를 누릅니다.
  2. Copilot의 답변을 검토하고 필요하면 프롬프트를 다듬습니다.

태스크 2 · 세션 아이디어 구상

앞에서 조사한 동향을 바탕으로 참석자에게 가치를 주는 세션 제목과 설명을 만듭니다. 흩어진 정보를 구체적인 의제 항목으로 옮기는 단계입니다.

  1. 같은 대화 창에서 다음 프롬프트를 입력합니다.
프롬프트그 트렌드를 바탕으로 고객 혁신 서밋에 어울리는 세션 제목 5개를 제안하고, 각각 짧은 설명을 작성해 줘.원문Based on those trends, suggest 5 engaging session titles and write short descriptions for a client innovation summit.
  1. Send를 선택하고 답변을 검토한 뒤 필요하면 프롬프트를 다듬습니다.
  2. 이어서 다음 후속 프롬프트를 입력합니다.
프롬프트설명을 활기차고 전문적인 어조로 다듬어서 더 매력적으로 만들어 줘.원문Make the descriptions more compelling by using an energizing and professional tone.
  1. Send를 선택하고 답변을 검토한 뒤 필요하면 프롬프트를 다듬습니다.

태스크 3 · 일정 시각화와 로고

Copilot Chat은 글로 된 아이디어를 시각 자료로 바꿔 줍니다. 여기서는 서밋 일정표와 주제를 담은 로고를 만들어 홍보와 행사 자료에 활용합니다.

  1. 같은 대화 창에서 다음 프롬프트를 입력합니다.
프롬프트[trend]에 초점을 맞춘 1일 서밋의 일정표를 만들어 줘. 오프닝과 클로징을 포함하고, 세션은 오전 9시, 오전 11시, 오후 1시 30분, 오후 3시에 배치해 줘. 중간 휴식 2번과 점심 시간 1시간을 넣고 표 형식으로 정리해 줘.원문Create an agenda timeline for a 1-day summit focused on [trend] with an introduction, closing, sessions at 9:00 AM, 11:00 AM, 1:30 PM, and 3:00 PM, two mini breaks, and an hour break for lunch in a table format.
참고

[trend] 부분을 태스크 1에서 나온 동향 가운데 하나로 바꿔 입력합니다.

  1. Send를 선택하고 답변을 검토한 뒤 필요하면 프롬프트를 다듬습니다.
  2. 이어서 다음 후속 프롬프트를 입력합니다.
프롬프트이 고객 혁신 서밋을 위한 심플하고 모던한 로고를 만들어 줘.원문Create a simple and modern logo for this client innovation summit.
  1. Send를 선택하고 Copilot이 만든 이미지를 검토한 뒤 필요하면 프롬프트를 다듬습니다.

태스크 4 · 기획 문서 작성

행사의 구조와 아이디어를 정리했으니, Copilot Chat으로 기획 요약서를 만들어 Word 문서로 옮깁니다. 이 문서가 목표, 세션 세부 내용, 성공 지표를 한곳에 모으는 프로젝트의 기준이 됩니다.

  1. 같은 대화 창에서 다음 프롬프트를 입력합니다.
프롬프트이 고객 혁신 서밋의 목표, 대상, 세션 주제, 주요 준비 일정을 담은 1페이지짜리 기획안을 만들어 줘.원문Create a 1-page planning brief for this client innovation summit that includes: goals, audience, session themes, and key planning milestones.
  1. Send를 선택하고 답변을 검토한 뒤 필요하면 프롬프트를 다듬습니다.
  2. 이어서 다음 후속 프롬프트를 입력합니다.
프롬프트이번 행사에서 예상되는 성과와 성공 지표를 요약하는 섹션을 추가해 줘.원문Add a section summarizing anticipated outcomes and success metrics for the event.
  1. Send를 선택하고 답변을 검토한 뒤 필요하면 프롬프트를 다듬습니다.
  2. 이제 Copilot에게 이 내용으로 Word 문서를 만들게 합니다. 다음 프롬프트를 입력합니다.
프롬프트이 기획안을 Word 문서로 만들어 줘.원문Create a Word document of this planning brief.
  1. 생성된 Word 문서를 엽니다.
  2. 로그인하라는 안내가 나오면 userx@yourtenant.onmicrosoft.com(테넌트 공급자 제공)을 입력하고 Next를 선택합니다.
  3. Enter password 화면에서 Password1(테넌트 공급자 제공)을 입력하고 Sign in을 선택합니다.
  4. Stay signed in?이 나오면 Don't show this again 확인란을 선택하고 Yes를 선택합니다.
  5. Blank document를 선택해 새 Word 문서를 엽니다.
  6. 문서 오른쪽 위에서 File을 선택하고 Save As를 선택해 문서를 저장합니다.
  7. Other Locations 아래에서 This PC를 선택하고, 위쪽 텍스트 상자에 파일 이름을 입력해 문서 이름을 정합니다. (예: Client Summit Planning Brief)
  8. Save를 선택한 뒤 문서를 닫습니다.
  9. Copilot Chat 대화로 돌아가 태스크 5를 이어 갑니다.

태스크 5 · 파일에서 콘텐츠 생성

태스크 4에서 만든 기획 요약서를 업로드하고, Copilot에게 요약과 내부 커뮤니케이션 초안을 만들게 합니다. 문서를 바로 쓸 수 있는 형태로 바꿔 시간을 아끼는 방법을 확인합니다.

  1. Copilot Chat에서 다음 프롬프트를 입력하고 태스크 4에서 만든 파일을 업로드합니다.
프롬프트이 기획안의 핵심 내용을 5개의 간결한 글머리 기호로만 요약해 줘.원문Summarize the key points from this planning brief into only 5 condensed bullet points:
  1. 프롬프트 상자 오른쪽 아래의 Add a file(클립 아이콘)을 선택해 파일 탐색기 대화 상자를 엽니다.
  2. 파일 탐색기 오른쪽에서 Documents를 선택해 태스크 4에서 저장한 문서를 찾습니다.
  3. 문서를 선택하고 파일 탐색기 아래쪽의 Open을 선택해 파일을 프롬프트 상자에 업로드합니다.
  4. 파일이 프롬프트 상자에 올라온 것을 확인하고 Send를 선택합니다.
  5. 답변을 검토하고 필요하면 프롬프트를 다듬습니다.
  6. 이어서 다음 후속 프롬프트를 입력합니다.
프롬프트이 요점과 다음 단계를 담아 기획팀에 보낼 후속 이메일을 작성해 줘.원문Write a follow-up email to the planning team with these highlights and the next step.
  1. Send를 선택하고 답변을 검토한 뒤 필요하면 프롬프트를 다듬습니다.

태스크 6 · Copilot Pages 협업

태스크 5에서 만든 이메일 초안을 Copilot Pages로 옮겨 협업 공간으로 바꿉니다. 여러 팀원이 실시간으로 내용을 다듬는 흐름을 체험합니다.

  1. 태스크 5의 마지막 답변(원하는 다른 답변도 됩니다) 아래에서 Edit in Pages를 선택해 내용을 Copilot Pages로 복사합니다.
  2. Copilot Chat 오른쪽 창에 새 Copilot Page가 열립니다. 다음 동작을 살펴봅니다.
    • 페이지 맨 위에서 새 제목을 붙입니다.
    • 페이지 아무 곳이나 클릭해 내용을 자유롭게 입력합니다.
    • 답변 아래의 Add to page를 선택해 이전 답변이나 새 답변을 페이지에 추가합니다.
    • /를 입력해 표나 체크리스트 같은 콘텐츠 블록을 삽입합니다.
    • 동료를 @mention하고(또는 그렇게 가정하고), 이름을 추가할 때 나타나는 메시지에서 Share and notify를 선택해 접근 권한을 부여합니다.
    • 필요하면 페이지 오른쪽 위의 Share 아이콘을 선택하고 두 옵션 중 하나로 링크를 복사해 페이지를 공유합니다.
